# 数据说明

f-tag 读取当前网页中的公开账号链接和用户名，用于匹配本机保存的用户标记。

本地保存的内容包括账号标识、等级、描述标签、用户填写的备注、来源链接、标记时间、白名单和自定义规则。恢复快照及撤销记录也保存在本机。

插件不设服务器，不上传这些内容，不收集遥测，也不使用浏览器云同步存储。

用户主动导出时，记录会写入 JSON 文件。文件的保存位置由浏览器和用户选择。清理扩展数据或卸载插件会删除本地记录；已经导出的文件不受影响。

`storage` 权限用于保存本地数据，`activeTab` 用于打开面板时读取当前站点。HTTP/HTTPS 内容脚本用于识别网页账号并显示标记，白名单站点不进行检查。
