# 商店资料

## 名称

f-tag

## 简介

给论坛用户设置等级、描述标签和备注，再次看到同一账号时显示之前的标记。所有记录保存在本机，支持 JSON 备份和恢复。

## 详细说明

f-tag 用来记录对论坛用户过往言论的判断。在用户名旁点击 Tag，可以设置等级、选择描述标签、填写备注和来源链接。

目前提供知乎、V2EX、NodeSeek、LINUX DO、Chiphell、吾爱破解和 Hostloc 的账号识别适配器，其他站点可以使用通用识别或自定义规则。网站页面结构、登录状态和移动版差异可能影响识别范围。

记录保存在本机，不需要账号，不上传到服务器。支持站点白名单、本地 JSON 导入导出、覆盖前恢复快照，以及最近一次标记操作的撤销。
