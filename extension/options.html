F-TAG

f-tag / 标签与记录

按账号保存等级、标签和备注。所有记录存储在本机。

用户等级

一个用户最多设置一个等级。名称与颜色可以修改。

描述标签

描述标签可多选，与等级分别保存。

本地备份

JSON 文件包含等级、标签、备注和站点设置。导入前自动保存本地恢复快照。

旧版本备份可导入新版；更高版本的备份会被拒绝，并提示升级。未适配站点的记录也会保留。

站点白名单

以下域名及其子域名免于检查，已有记录仍会保留。

站点适配

内置知乎、V2EX、NodeSeek、LINUX DO、Chiphell、吾爱破解、Hostloc。其他站点默认识别 /member/、/users/、/user/、/u/ 账号链接；可添加自定义规则。

自定义规则（JSON）

selector 选择用户名链接，prefix 是账号路径前缀。每个域名一条规则。修改路径前缀可能改变用户标识。

已标记用户

按站点和账号标识分别保存。内置站点的 www 和主域名使用同一账号记录，同名用户不会合并。暂未适配的站点记录同样保留。

用户 / 账号 站点 等级 / 标签 / 备注 操作
暂无匹配记录。在网页用户名旁点击 Tag，即可开始标记。
